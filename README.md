# ShopProject — Учебный интернет-магазин

Простой многостраничный веб-сайт интернет-магазина, разработанный в рамках учебного курса по направлению **«Фронтенд и бэкенд разработка»**. Проект демонстрирует навыки построения семантической HTML-структуры, работы со стилями CSS и базовой валидации форм.

## 🚀 Цели и задачи проекта

- Разработка понятной и доступной HTML-структуры.
- Использование семантических блоков страниц (`<header>`, `<main>`, `<section>`, `<footer_>`).
- Организация стилей с помощью методологии **БЭМ** (Блок-Элемент-Модификатор).
- Подключение и настройка внешнего файла CSS.
- Подготовка базы для последующего превращения сайта в полноценный многостраничный веб-ресурс.

---

## 🛠 Технологический стек

*   **HTML5** — семантическая разметка.
*   **CSS3** — кастомная сетка, позиционирование элементов, псевдоклассы доступности (`:focus-visible`, `:target`).
*   **JavaScript** (в перспективе) — перехват событий отправки (`preventDefault`) и динамическая валидация элементов интерфейса.

---

## 📂 Структура страниц сайта

Проект состоит из пяти ключевых страниц, обеспечивающих полноценный пользовательский путь интернет-магазина:

1.  **Главная страница (`index.html`)** — приветственная секция учебного проекта, блок с ключевыми преимуществами разработки и витрина популярных товаров.
2.  **Каталог товаров (`catalog.html`)** — страница со списком доступной продукции, включающая в себя сайдбар с фильтрами по категориям и диапазону цен.
3.  **Карточка товара (`product.html`)** — детальная страница конкретной позиции.
4.  **Оформление заявки (`order.html`)** — страница с формой заказа, содержащая обязательные для заполнения поля ввода (Имя, Фамилия, E-mail).
5.  **Контакты (`contacts.html`)** — информационная страница компании. Включает каналы связи (номер телефона, e-mail) и встроенную интерактивную карту (Яндекс Карты).
